📝 أنشئ حساب GitHub

GitHub هو المكان الذي سنحفظ فيه كود الموقع:

👉 اذهب إلى:

https://github.com

الخطوات:

  1. اضغط "Sign up"
  2. أدخل بريدك الإلكتروني
  3. اختر كلمة مرور قوية
  4. أكمل التحقق من البريد
2

🖥️ تثبيت Git على الكمبيوتر

Git هو البرنامج الذي سنستخدمه لرفع الملفات:

👉 حمّل من:

https://git-scm.com

اختر نظام تشغيلك (Windows, Mac, Linux)

بعد التثبيت:

  1. أعد تشغيل الكمبيوتر (اختياري)
  2. افتح Terminal/Command Prompt
  3. اكتب: git --version
  4. يجب أن ترى رقم الإصدار
3

📤 رفع المشروع على GitHub

افتح Terminal وانتقل لمجلد المشروع:

# Windows: اضغط Windows + R ثم اكتب cmd # Mac: Command + Space ثم اكتب terminal # Linux: Ctrl + Alt + T # انتقل لمجلد المشروع cd D:\clinic # أو إذا كان على Mac cd /Users/yourname/clinic

الآن أكتب هذه الأوامر بالترتيب:

git init git add . git commit -m "Initial commit - osraaccounting" git branch -M main git remote add origin https://github.com/yourusername/osraaccounting.git git push -u origin main
⚠️ ملاحظة: استبدل "yourusername" باسم حسابك على GitHub

النتيجة: جميع ملفات مشروعك متاحة الآن على GitHub!

4

🎯 أنشئ حساب Vercel

👉 اذهب إلى:

https://vercel.com

الخطوات:

  1. اضغط "Sign Up"
  2. اختر "Continue with GitHub"
  3. وافق على الأذونات
  4. تم! 🎉
5

🚀 Deploy المشروع

الآن سنرفع الموقع على الإنترنت:

  1. بعد تسجيل الدخول إلى Vercel
  2. اضغط "New Project"
  3. اختر مستودع osraaccounting
  4. اضغط "Import"
  5. ترك الإعدادات كما هي
  6. اضغط "Deploy"
  7. انتظر 2-5 دقائق
✅ تهانينا!
موقعك متاح الآن على الإنترنت! 🎉

الرابط: https://osraaccounting.vercel.app
⚡

🔄 تحديث الموقع (سهل جداً)

عند إضافة تحسينات جديدة على الموقع:

1. عدّل الملفات على الكمبيوتر

أضف التحسينات التي تريدها

2. افتح Terminal

انتقل لمجلد المشروع

3. أرسل التحديث

استخدم git push

4. Vercel يتحدث تلقائياً!

✅ الموقع محدث الآن

cd path/to/project git add . git commit -m "تحديث v1.2.1" git push
✨ هذا كل شيء! Vercel سيتولى الباقي تلقائياً
