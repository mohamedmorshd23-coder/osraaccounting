# 🏥 osraaccounting - نظام حسابات العيادة

نظام حسابات متكامل وسهل الاستخدام لإدارة أيام ودفعات الأطباء والمصروفات والرواتب.

## ✨ المميزات الرئيسية

### 📋 إدارة الأيام والدفعات
- ✅ تسجيل دفعات يومية لكل طبيب
- ✅ تجميع تلقائي للدفعات المتعددة في نفس اليوم
- ✅ فصل الدفع (كاش + فودافون)
- ✅ حساب النسب الطبية تلقائياً

### 👨‍⚕️ إدارة الأطباء
- ✅ إضافة وتعديل وحذف الأطباء
- ✅ تحديد نسبة الطبيب من الدخل
- ✅ تقارير شاملة لدخل كل طبيب

### 💰 إدارة المصروفات
- ✅ تسجيل المصروفات اليومية
- ✅ تصنيف المصروفات (كهرباء، مياه، مرتبات، إلخ)
- ✅ حساب الصافي التلقائي

### 💼 إدارة الرواتب
- ✅ نظام رواتب متقدم مع حساب الساعات
- ✅ تسجيل الدخول والخروج اليومي
- ✅ حساب الراتب النهائي تلقائياً
- ✅ تصدير كشوفات راتب PDF

### 📊 التقارير والتحليلات
- ✅ لوحة تحكم شاملة
- ✅ مقارنة الفترات المختلفة
- ✅ تقارير مفصلة لكل طبيب
- ✅ ملخص شهري متكامل

### 🔐 الأمان والحماية
- ✅ نظام دخول بكلمة سرية

## 🚀 البدء السريع

### المتطلبات
- Node.js 18+ 
- npm أو yarn

### التثبيت المحلي
```bash
# 1. استنساخ المشروع
git clone https://github.com/username/osraaccounting.git
cd osraaccounting

# 2. تثبيت الحزم
npm install

# 3. تشغيل التطبيق
npm run dev

# 4. الفتح في المتصفح
# افتح http://localhost:5173
```

### الدخول الافتراضي
- **الرقم السري الافتراضي**: 7229590
