### الخيار 2: ترقية Recharts إلى v3 (متقدم)

**إذا أردت الترقية:**

```bash
# على جهازك المحلي:
npm install recharts@latest

# أو بشكل صريح:
npm install recharts@3.0.0
```

**⚠️ تحذير:**
```
قد تحتاج إلى تعديلات طفيفة في الكود
اختر هذا الخيار إذا كنت متأكداً
```

### الخيار 3: تحديث package.json (متقدم)

**في الملف package.json:**

```json
// البحث عن:

// واستبدالها بـ:

```

**ثم:**
