## 🚀 الخطوات الأساسية (5 خطوات فقط):

### ✅ الخطوة 1: تثبيت Node.js

**ماذا هو Node.js؟**
- برنامج يسمح لك بتشغيل JavaScript على الكمبيوتر
- يتضمن npm (مدير المكتبات)
- مجاني وسهل

**خطوات التثبيت:**

```
1. اذهب إلى: https://nodejs.org
2. اضغط الزر الأخضر "LTS" (موصى به)
3. حمّل النسخة المناسبة لنظام تشغيلك
4. ثبت البرنامج (Next → Next → Finish)
5. أعد تشغيل الكمبيوتر (اختياري)
```

**التحقق من التثبيت:**

افتح Terminal/Command Prompt واكتب:

```bash
node --version
npm --version
```

**النتيجة المتوقعة:**
```
v20.x.x  (أو إصدار أحدث)
10.x.x   (أو إصدار أحدث)
```

## 🚨 مشاكل شائعة والحل:

### المشكلة: "node is not recognized"

**الحل:**
```
1. Node.js لم يُثبت بشكل صحيح
2. أعد تثبيت Node.js من nodejs.org
3. أعد تشغيل الكمبيوتر
4. حاول مرة أخرى
```

### المشكلة: "npm install أخطأ"

**الحل:**
```
1. تأكد من وجود package.json في المجلد
2. حاول حذف مجلد node_modules والملف package-lock.json
3. اكتب: npm install مرة أخرى
```

### المشكلة: "Port 5173 مستخدم"

**الحل:**
```
1. غلق البرنامج الآخر الذي يستخدم الـ Port
2. أو استخدم port مختلف
3. اكتب: npm run dev -- --port 5174
```

### المشكلة: "لا يعمل البرنامج"

**الحل:**
```
1. تأكد من تثبيت Node.js بشكل صحيح
2. تأكد من وجود جميع الملفات
3. اكتب: npm install مرة أخرى
4. أعد تشغيل Terminal
```
